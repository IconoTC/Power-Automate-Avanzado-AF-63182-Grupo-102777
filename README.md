# Power Automate Avanzado

Materiales de apoyo para el curso **Power Automate Avanzado**. El repositorio reúne soluciones, archivos de ejemplo y recursos para practicar los procesos de automatización trabajados durante el curso.

## Contenido

- [Solución base](0.%20Solución%20base/): paquete inicial del curso (`CursoPautomate_1_0_0_3.zip`).
- [Carga inicial](1.%20Carga%20inicial/): hojas de Excel para cargar productos y cuentas.
- [Carga de pedidos](2.%20Carga%20de%20pedidos/): cinco pedidos de ejemplo en PDF.
- [Plantilla de factura](3.%20Plantilla%20de%20factura/): plantillas de factura en Word, incluida una versión prerrellena.
- [Facturas OCR PAD](4.%20Facturas%20OCR%20PAD/): cinco facturas de ejemplo en PDF para prácticas de OCR con Power Automate Desktop.
- [Excel a combinar](5.%20Excel%20a%20combinar/): archivos mensuales de ventas de enero a diciembre de 2025 para ejercicios de combinación.
- [Tarjetas adaptables](6.%20Tarjetas%20adaptables/): ejemplos JSON para escenarios de aprobación y rechazo.
- [Software de facturación](7.%20Software%20de%20facturación/): paquete `Software facturación V2.zip`.
- [Presentación del instructor](Presentación%20Instructor%20Curso%20Power%20Automate%20Avanzado.pdf): material de presentación del curso.
- `CursoPautomate_1_0_0_4.zip`: paquete adicional de la solución del curso.
